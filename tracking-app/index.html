ℹ️ À Propos

Sprint 4 - Consultation des Demandes et Suivi en Temps Réel

Cette application permet de :

  • 🔍 Rechercher une demande par numéro de passeport
  • 🎟️ Suivre une demande grâce au code de suivi
  • 📲 Générer des QR codes uniques pour le partage
  • 📋 Consulter l'historique complet des statuts

Framework : Vue.js 3
Version Simple : Application monolithique (~300 lignes)
Version Composants : Architecture modulaire (~450 lignes)
Zéro dépendances : Vue.js via CDN, pas de build process
